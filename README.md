# 核电上市公司核心指标走势图

中国广核（003816）与中国核电（601985）上市以来核心指标走势的交互式折线图（ECharts），公网可访问。

## 页面

- [中国广核（003816）](./cgn.html) — 2019 年上市以来
- [中国核电（601985）](./cnnp.html) — 2015 年上市以来

## 指标维度

- 反应堆规模：在运机组(台)、在运+在建(台)、装机容量(万千瓦)
- 市值：总市值、还原分红市值（分红前估值）
- 估值密度：市值/在运万千瓦、平均市值/总规模万千瓦
- 估值区间：地板估值、天花板估值
- 估值倍数：市盈率PE、市净率PB、每股股利

## 数据说明

- 财务/行情数据：腾讯行情、东方财富公开接口（季度频率）
- 反应堆规模：基于公开披露信息的整理/估算值，逐年精确值需核实
- 原始数据：`cgn_data.csv`、`cnnp_data.csv`
