# A股核电及发电企业核心指标走势图

中国广核（003816）、中国核电（601985）及 57 家 A 股发电企业的核心指标交互式折线图（ECharts）。

## 架构：数据与页面分离 + 共用元素

```
deploy/
├── index.html             主页（分类导航）
├── compare.html           横向比较页（跨公司同指标对比）
├── cgn.html / cnnp.html   核电页面（极简壳）
├── power/<代码>.html      57 家发电企业页面（极简壳）
│
├── css/style.css          ← 共用样式（唯一一份）
├── js/echarts.min.js      ← 共用图表库
├── js/chart.js            ← 共用渲染逻辑（核电/装机容量/纯财务 三种模式）
│
└── data/                  ← 数据与页面分离
    ├── <代码>.js            每家公司独立数据（带中文字段注释，可手动编辑）
    ├── companies_data.js   聚合数据（横向比较页用）
    └── raw/                 原始数据归档（csv/md/json）
```

### 数据与页面分离

- 每个公司的完整数据独立存放在 `data/<代码>.js`（JS 对象字面量，非 JSON）
- 数据文件顶部有**中文字段说明注释**，便于人工阅读与修改（改完刷新页面即生效）
- 页面 HTML 只是极简壳（约 0.85KB），用 `<script src="data/<代码>.js">` 加载数据后由 `js/chart.js` 渲染
- 用 script 加载（而非 fetch）是因为 **file:// 本地打开时 fetch 会被浏览器 CORS 禁止**，script 加载则可用
- 更新数据无需改动页面，重跑 `scripts/build_data.py` 即可

### 共用元素

- **渲染逻辑**：`js/chart.js` 唯一一份，自动识别三种模式
  - 核电：反应堆规模（在运/在建机组、装机万千瓦）+ 估值密度
  - 装机容量：装机容量万千瓦 + 估值密度
  - 纯财务：市值/PE/PB/分红
- **样式**：`css/style.css` 唯一一份
- **图表库**：`js/echarts.min.js` 唯一一份

## 指标维度

- 规模：在运机组(台)、在运+在建(台)、装机容量(万千瓦)
- 市值：总市值、还原分红市值（分红前估值）
- 估值密度：市值/装机万千瓦、平均市值/装机万千瓦
- 估值区间：地板估值、天花板估值
- 估值倍数：市盈率PE、市净率PB、每股股利

## 数据说明

- 财务/行情：腾讯行情、东方财富公开接口（季度频率）
- 反应堆规模、装机容量：基于公开披露信息整理/估算，逐年精确值需核实
- 11 家龙头的装机容量为估算值，源头见 `scripts/power_meta.py`
